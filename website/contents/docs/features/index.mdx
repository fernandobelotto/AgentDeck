## Feature Overview

### Real-time Status Display

AgentDeck displays animated icons that update in real-time based on your AI assistant's state:

- **Idle**: Ready for input
- **Running**: Processing a request
- **Tool Use**: Executing a tool
- **Editing**: Modifying files
- **Question**: Waiting for user input
- **Permission**: Pending approval
- **Error**: An error occurred
- **Disconnected**: Session not connected

### Gesture Controls

Control your AI assistant without leaving your keyboard:

| Gesture | Action |
| ------- | ------ |
| Single Press | Focus terminal window |
| Double Press | Cancel current operation |
| Hold (500ms) | Approve pending permission |

### Multi-Instance Support

Assign each Stream Deck key to a different AI session:

- Monitor multiple Claude Code instances
- Monitor multiple Gemini CLI instances
- Mix and match different AI assistants

### Terminal Integration

Deep integration with terminal applications:

- Focus terminal windows
- Send keyboard signals
- Launch new AI instances
- Works with Kitty, iTerm2, Terminal.app, and more
